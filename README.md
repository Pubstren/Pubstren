## 关于

在做量化研究，顺手把研究需要的基础设施自己搭起来。

**研究方向** — 因子与横截面分析。习惯是先写死检验条件，再跑数据。

**在建设** — 预测市场全量订单簿采集。单机运行，压缩后约 1 TB / 月，冷数据外置归档。

**在学** — C++ 与 Rust，以及事件驱动回测引擎的内部实现。

## 项目

- **[csi](https://github.com/Pubstren/csi)** — 数据采集程序。负责数据的持续采集与落盘。
- **[plymouth-skill](https://github.com/Pubstren/plymouth-skill)** — 个人工作流 skill（Python）。把重复的操作固化成可复用的技能。
- **[C-](https://github.com/Pubstren/C-)** — C++ 学习记录。从基础语法开始，边学边写。

这台开发机的名字来自一艘皇家海军的特别计划舰。

她的设定里有一条我觉得挺对的：忠诚不是条件反射式的服从，而是在评估过效忠对象之后，主动做出的选择。
